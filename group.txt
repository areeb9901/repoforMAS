I have investigated the error popup appearing on the Overlapped Executed Derivative Agreements dashboard in UAT2.

Root Cause:

One of the agreements displayed on the dashboard (MA ID: 519798) had a blank Status value. The dashboard grid expects a valid Status for each agreement and fails to render the row when this value is null, resulting in the warning popup.

The issue was observed only in UAT2 because DEV did not have any agreements with a blank Status. As discussed with Bhavani yesterday, this is an extremely rare scenario caused by a race condition in which the MA Status can be set to null.

Proposed Fix:

Handle null Status values gracefully on the dashboard to prevent the error popup.

The fix version can be decided by Eva and the BA team.
